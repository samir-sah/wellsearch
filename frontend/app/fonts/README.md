# Montserrat

`montserrat-latin-variable.woff2` is the unmodified Latin subset of Montserrat,
normal style, variable weights 100–900, distributed under the SIL Open Font
License in `OFL.txt`.

- Font: <https://fonts.gstatic.com/s/montserrat/v31/JTUSjIg1_i6t8kCHKm459Wlhyw.woff2>
- Stylesheet: <https://fonts.googleapis.com/css2?family=Montserrat:wght@100..900&display=swap>
- License: <https://github.com/google/fonts/blob/main/ofl/montserrat/OFL.txt>

The root layout loads it with `next/font/local` and exposes
`--font-montserrat`. Font loading needs no external runtime request.
